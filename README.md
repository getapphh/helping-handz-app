# Helping Handz

This package uses the approved Helping Handz artwork unchanged.

Upload ALL files in this folder to the ROOT of your GitHub Pages repository, replacing the old app files.
Do not upload the ZIP itself.

GitHub Pages will automatically redeploy after you commit the changes if Pages is already enabled.

Customer-facing controls:
- GET HELPING HANDZ: triggers the supported browser app/home-screen flow.
- OPEN APP: opens https://helpinghandzonline.square.site/

The services are part of the background artwork and are intentionally not tappable.
